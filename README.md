## ✨ Про проєкт та ідею

Більшість сучасних таск-трекерів перевантажені зайвими налаштуваннями, складними таблицями та викликають тривогу через нескінченні списки справ. **Demak** розв'язує цю проблему, розділяючи роботу на два спокійні простори:
* **My day** — фокус виключно на поточному дні, прогрес у відсотках та погодинний розклад.
* **My tasks** — загальний простір усіх планів із фільтрацією за списками та пріоритетами.

**Цільова аудиторія:** всі, хто хоче організувати навчальні дедлайни й щоденні справи в естетичному, легкому інтерфейсі без зайвої бюрократії.

## 🚀 Основний функціонал

* 🔐 **Персональні акаунти:** Швидка реєстрація та вхід лише за логіном і паролем (без прив'язки до пошти чи телефону) з ізольованим збереженням даних для кожного користувача.
* 🎨 **8 персонажів та динамічних тем:** Користувач обирає свого маскота (*Кит, Котик, Пінгвінчик, Жабка, Курчатко, Лисичка, Зайчик, Ведмедик*), і весь інтерфейс миттєво адаптує кольорову гаму під нього.
* 📊 **Аналітика продуктивності:** 
  * Кільцевий індикатор денного прогресу (*Today's progress*).
  * Стовпчиковий графік активності за останні 7 днів (*Your rhythm*).
* 📅 **Інтерактивний календар та розклад:** Навігація по місяцях, індикація днів із запланованими справами та автоматичне формування погодинного розкладу.
* 🗂️ **Гнучке керування задачами:** 
  * Встановлення дати та часу дедлайну.
  * 3 рівні пріоритетів (*Low*, *Medium*, *High*) із швидким перемиканням.
  * Створення та видалення власних тематичних груп-списків.
  * Кастомні модальні вікна, святкове конфетті при реєстрації та спливаючі сповіщення від маскота.

## 📖 Щоденник розробки (Хронологія та трекер задач)

### Етапи еволюції проєкту
1. **Проєктування в Figma:** Створення концепції *«calm place»*, відмальовка 8 маскотів та макетів екранів *My day* і *My tasks*.
2. **Перший прототип на C++ (ImGui):** Спроба реалізації десктопної версії у CLion. Під час тестування стало зрозуміло, що десктопний C++ ускладнює поширення програми між користувачами та верстку сучасної векторної графіки.
3. **Архітектурний розворот (Pivot на Web):** Перенесення проєкту на веб-стек (HTML/CSS/JS), що дозволило додати анімації, кастомні модальні вікна, систему акаунтів та розгорнути проєкт онлайн.
4. **Фінальне полірування:** Заміна системних браузерних вікон на внутрішні модалки, додавання рівнів пріоритетів та публікація на GitHub Pages.

## 🔍 Ретроспектива

* **Що вдалося добре:** Дизайн із Figma на 100% збігається з фінальним продуктом. Особливо вдалими вийшли жива зміна кольорових тем під персонажа та миттєва реакція аналітики на виконання задач.
* **Що було складним:** Початкова спроба реалізувати сучасний UI на C++ забрала час на налаштування середовища. Також довелося вимикати агресивне автозаповнення браузера в полях вводу.
* **Вдалі рішення:** Вчасний перехід на Web-стек і використання CSS-змінних для тем оформлення.
* **Плани на майбутнє (Що не встигли):** Підключення хмарної БД (Firebase/Supabase) для синхронізації між смартфоном і ноутбуком, звукові ефекти та вбудований Pomodoro-таймер.
